# 投稿一覧ページのカードリンク化とタグ表示

## Summary

投稿一覧の各 `article.post` 全体を投稿詳細へのクリック領域にする。
現在表示しているテキストの「詳細」リンクは削除する。
さらに、詳細ページと同じタグリンク表示を一覧の各投稿にも追加し、配置は「本文の下、日付の上」とする。
カードに hover 表現を追加し、投稿全体がリンクであることを視覚的に分かるようにする。

## Key Changes

- 一覧の `article.post` に詳細ページへの不可視リンクを追加する。
  - `article` 全体をクリック可能にするため、`article` 直下に絶対配置のリンクを置く。
  - タグリンクとのネストを避けるため、`<a><article>...</article></a>` にはしない。
  - リンク文言「詳細」は画面上から削除し、`aria-label` で「投稿詳細を表示」のように補足する。
- 投稿カードの hover 表現を追加する。
  - 一覧投稿に hover したとき、カード周囲に影を付ける。
  - レイアウトが動かないように、border 幅や余白ではなく `box-shadow` で表現する。
  - `cursor: pointer` を付け、投稿全体がリンクであることを示す。
- 一覧投稿にタグ表示を追加する。
  - 詳細ページと同じ `post__tags` 構造を使う。
  - `post.tags` が空の場合はタグ領域を表示しない。
  - 配置は `post__body` の後、`post__meta` / 日付の前。
- レイアウト維持のため CSS は最小限にする。
  - `.post` を `position: relative` にする。
  - 不可視リンクを `position: absolute; inset: 0;` で重ねる。
  - タグリンクは詳細リンクより前面に出して、タグページへのクリックを維持する。
  - 既存の余白、カード幅、本文、日付の見た目は変更しない。

- リンクは `article.post` のクリック領域として機能する構造にする。
- 既存の投稿者、本文、日付の表示順は維持する。
- 投稿カードに hover したとき、投稿の周りに影が付く。
- 投稿カードに `cursor: pointer` を付け、クリック可能であることを示す。
- hover 表現によってカードの余白や高さは変わらない。

### Increment 2: 一覧投稿にタグリンクを表示する

#### 要件

- タグリンクの遷移先は `/tags/{タグ名}`。
- タグ表示位置は本文の下、日付の上。
- タグなし投稿では `post__tags` 領域を表示しない。
- 詳細ページのタグ表示仕様は変更しない。

## Assumptions

- 「現在の詳細リンクは削除」は、画面上のテキストリンク「詳細」を削除する意味とする。
- カード全体リンクは不可視の `<a>` を `article.post` に重ねる方式にする。
- hover 表現は一覧の投稿カードに適用し、詳細ページの単体投稿カードには適用しない。
- 一覧に表示するタグは `post.tags` を使い、詳細ページと同じタグリンク仕様にする。
- タグリンククリックはタグページ遷移を優先し、カード全体リンクとは競合させない。
